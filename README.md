# Comeback Momentum, Chart Re-Entry, and Fandom Intensity Analysis of South Korea Top 50 Playlist

## 📌 Project Overview
This project analyzes South Korea's Top 50 playlist to identify chart re-entries, comeback momentum, retention, rank recovery, and observable patterns related to fandom intensity.

## 🎯 Objectives
- Identify songs with repeated chart re-entries.
- Analyze comeback momentum and rank recovery.
- Measure post-comeback retention.
- Compare album and content attributes.
- Develop a Fandom Intensity Proxy.

## 🛠️ Technologies
- Python
- Pandas
- NumPy
- Plotly
- Streamlit
- Google Colab
- GitHub

## 📊 Dashboard
The Streamlit dashboard provides:
- Re-entry Timeline
- Momentum Analysis
- Content Attribute Analysis
- Fandom Intensity Proxy
- Data Quality Analysis
- Interactive Filters
